# D2 authoring rules

D2 (https://d2lang.com) renders complex flowcharts, system design, and `sql_table` database models. The `diagramming.mjs` wrapper owns the theme and layout — sources carry content and, at most, category accent strokes.

## Theme contract (handled by the script, never in the source)

- `--theme=201` (Dark Flagship Terrastruct) + canvas recolor `#000410 → #0a0a0a` to match the shared page background.
- Layout: TALA when installed, elk otherwise. Sequence diagrams ignore the layout engine (D2 renders them itself).
- Fonts: MesloLGS NF Regular/Bold when present on disk, embedded into the SVG.
- Sources stay free of `vars.d2-config.theme-id` and page-chrome styling.

## Allowed in-source styling: category accents

One `style.stroke` per node, from the shared palette:

| Category | Stroke |
|---|---|
| Client / browser / data-key | `#3291FF` |
| Server / derived keys | `#A78BFA` |
| Data stores / encrypted payloads | `#3ECF8E` |
| Auth roots / authenticator | `#E5484D` |
| Neutral storage / metadata | `#52525B` |
| External systems | `#EDEDEF` |

A dark-card base is already applied by convention at the top of every source:

```d2
**.style: {
  fill: "#111113"
  font-color: "#EDEDEF"
}
```

## Syntax gotchas (each one broke a real render)

- **Quote every label** containing parentheses, slashes, dashes, or dots — `login: "login — GitHub sign-in"`, not `login: /login`. Unquoted-string errors ("unexpected text after unquoted string") mean unquoting.
- **Reserved ids**: `label`, `style`, `shape`, `near`, `link`, `constraint` cannot be node names or edge labels (`reserved keywords are prohibited in edges`).
- **`sql_table`**: the table label takes no newline ("shape sql_table cannot have newlines in label"). Columns are `name: type` plus `pk` / `fk` / `{constraint: unique}`.
- **Sequence diagrams**: root `shape: sequence_diagram`; branches are named blocks (`"existing vault": { … }`), and labels must be quoted when they contain punctuation.
- **Auto-created nodes**: writing an edge to an undefined path (`browser.rpc -> server.rpc`) silently creates a phantom `browser.rpc` inside `browser`. Point edges at defined nodes (`browser -> server.rpc`).
- Container-heavy graphs lay out badly on TALA — flatten nested packages into single labeled nodes (`"Browser\nReact UI · WebCrypto · passkey PRF"`) when boxes start floating outside their parent.

## Layout engine install (only when TALA is missing)

TALA ships separately from d2: grab the release matching the d2 plugin protocol from `github.com/terrastruct/TALA/releases` (d2 0.9.x pairs with tala 0.4.x) and put `d2plugin-tala` on `PATH`. The script falls back to elk automatically, so this is a quality upgrade, never a blocker.
